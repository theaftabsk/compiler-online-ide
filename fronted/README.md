# 🖥️ Universal Digital Lab Frontend Client

Modern web application for the Centralized University Digital Programming Lab & Practical Monitoring System.

## Features
* 💻 **Monaco Code Editor (VS Code Engine)**: Supports C, C++, Java, and Python with auto-completion and syntax highlighting.
* ⚡ **Live 60-Machine Grid Dashboard**: Faculty can monitor PC-01 to PC-60 in real-time.
* 👁️ **Live Code Peek Inspector**: Faculty can click any PC card to view live streaming code and compilation errors.
* 🚨 **Anti-Cheating Guard**: Tab-switching and focus loss detection with faculty alerts.
* 📊 **HOD / Dean Analytics**: Detailed attendance, pass rates, and exportable PDF/printable reports.

## How to Run Frontend
You can open `index.html` directly in any web browser (Chrome, Edge, Firefox, Brave) or run a local web server:

```bash
# Option 1: Double click or open in browser
start index.html

# Option 2: Run with local HTTP server
npx serve -s . -l 3000
```
